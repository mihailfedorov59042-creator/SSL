# Старославянский язык

[Открыть приложение](https://mihailfedorov59042-creator.github.io/SSL/)

- **Приложение → Установить** добавляет сайт на компьютер или телефон. На iPhone в Safari используется **Поделиться → На экран «Домой»**.
- После первой загрузки приложение хранит все три раздела для чтения без сети.
- Обновления проверяются при запуске, возврате к приложению и восстановлении связи. В меню есть кнопка **Проверить обновления**. После скачивания новой версии можно нажать **Обновить** или **Позже**.
- **Скачать HTML** сохраняет отдельную копию для открытия из файловой системы. Обновления получает приложение, установленное с сайта.

GitHub Pages публикует корень ветки `main`. Чтобы выпустить новую версию, измените `index.html` и сохраните его в `main`. Приложение сравнит опубликованный HTML с сохранённой версией и скачает его целиком. Сохраняйте метку `ssl-app` в начале HTML и разметку меню приложения.

## Раздельная установка PWA

У этого приложения собственный `id` с путём репозитория. Указывать `id: "./"` нельзя: относительный идентификатор PWA разрешается от корня origin, и приложения одного аккаунта GitHub Pages получают одинаковую идентичность. `start_url` и `scope` остаются в папке приложения. Данные браузера не очищаются.

Если Android уже объединил старые установки, серверное обновление не гарантирует автоматического разделения существующих ярлыков. Сначала сохраните резервную копию важных данных, затем откройте точные адреса `/book-mixa-3/` и `/SSL/` в Chrome и установите каждое приложение отдельно. Удалять данные всего домена GitHub Pages не нужно. Старый объединённый ярлык удаляйте только после проверки новых установок и резервных копий.
